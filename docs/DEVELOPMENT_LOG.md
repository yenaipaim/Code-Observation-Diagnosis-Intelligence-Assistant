## 阶段 11：修复诊断更新抢焦点

- 移除诊断监听和运行时输出分析的自动聚焦，只更新状态、装饰和 CodeLens。
- 保留 CodeLens、编辑器标题按钮和显式命令的用户主动聚焦行为。
- 增加自动路径禁止抢焦点、显式命令保留聚焦的回归测试，测试总数增至 74。
- 发布版本提升至 `0.1.5`。

## 阶段 12：修复诊断清空误判跑通

日期：2026-09-24

- 定位 diagnostics 短暂清空时会调用 `markCodeFixed()`，导致用户删除再补回报错的右括号后误判代码跑通。
- 诊断清空只清除报错装饰和 CodeLens，不再触发通关或计分。
- 仅当用户显式运行 Python 文件且子进程退出码为 `0` 时，才判定代码修好。
- 增加诊断清空不判跑通、显式运行成功才判跑通的回归测试，测试总数增至 76。
- 发布版本提升至 `0.1.6`。

## 阶段 13：只接收运行后的终端报错

日期：2026-09-24

- 移除 `vscode.languages.onDidChangeDiagnostics` 订阅，编辑器波浪线和语言服务器静态诊断不再进入闯关流程。
- 保留显式“运行当前 Python 文件并分析”和 VSCode 终端 shell integration 的 traceback 捕获。
- 只有实际运行产生 Python traceback 时才打开诊断入口、装饰报错行和生成 CodeLens。
- 增加编辑器诊断不进入流程、终端执行仍提供运行时错误的回归测试，测试总数增至 77。
- 发布版本提升至 `0.1.7`。

## 阶段 14：识别终端运行成功

日期：2026-09-24

- 定位终端运行路径只分析 traceback，没有处理命令退出码，导致修好代码并成功运行后面板不更新。
- 将终端执行开始和结束事件配对，保存每次 Python 命令的终端输出。
- 终端退出码为 `0` 且没有 Python traceback 时，如果命令运行的是当前关卡文件，则清除报错装饰并调用 `markCodeFixed()`。
- 终端命令识别限定 Python 解释器，避免 `cat main.py` 等普通命令误判为代码跑通。
- 增加终端 Python 脚本路径解析、解释器命令识别和终端成功判通的回归测试，测试总数增至 80。
- 发布版本提升至 `0.1.8`。

## 阶段 15：关卡绑定、重复评分与 AI 接近度

日期：2026-09-24

- 终端每次运行报错都开题或恢复当前关卡，不再用重复错误页吞掉再次出现的报错。
- 使用文件、误概念、报错原文和错误代码窗口生成稳定 `challengeKey`，并写入学习日志与学习者模型。
- 重复完成的关卡按 `0.5^n` 计分；清除时间线不会重置重复次数，一键清除才重置关卡历史。
- 删除查看答案的固定尝试次数门槛；点击答案前使用模态确认，查看答案不加分。
- 首次评判前生成标准答案缓存，AI 同时比较用户理解或当前运行代码与标准答案的接近度。
- 面板显示 AI 接近度、重复关卡次数和本关得分系数。
- 增加重复开题、半衰减、清时间线保留关卡历史、答案确认、无门槛答案和 AI 标准答案对比回归测试，测试总数增至 89。
